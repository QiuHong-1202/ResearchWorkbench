# 准备审稿材料

本文件用于整理和完整准备模式；共用定位与审稿规则由技能入口处理。

## 识别材料

识别 `submission/` 中的主论文、补充 PDF 及已有记录；`review-form/` 和 `related/` 不纳入论文准备。视频、代码和数据列为非 PDF 材料。完整流程需要压缩包内的补充 PDF 时，在项目任务临时目录安全解包，保留所需 PDF 到 `submission/`；只整理模式保留压缩包即可。缺少已知必需材料时报告缺失，使用审稿版本。

## 整理与归档

已有稿件目录优先复用，并在只整理和完整准备模式中补建缺失的空 `related/`；同名路径为文件时报告冲突。历史产物保留原位置，不为统一布局搬动。

新稿件根据用户说明、文件名、PDF 首页和邀请或表单确认年份、会议/期刊、编号与材料归属，建立 `<REVIEW_WORKSPACE>/<year>-<venue>-<paper-id>/`。年份采用已确认投稿届次，不从当前日期或下载时间推断；必要信息缺失时先询问。多篇按稿件身份分组，不把归属不明的附件复制到所有稿件。

- 按 [审稿规则](rules.md) 创建标准子目录。作者提供的正文及附件放入 `submission/`，表单、邀请和具体要求放入 `review-form/`，目录型附件保留内部结构。
- 默认复制并保留原件和原始文件名；内容相同或已在目标位置则复用，同名异内容先报告冲突。复制后核对大小及 SHA-256，不清理源目录。
- 仅当 `review.md` 缺失时从技能内的 [空白模板](../assets/review.md) 创建，填写已确认元信息。已有草稿与归档版本按审稿规则保留。
- 只整理模式汇报目录、归类、复用及未归类文件，不生成阶段完成记录。缺少正文时可归档明确附件，并报告材料不完整。

## 四个独立阶段

完整准备前读取 [执行配置与续跑](execution.md) 及 [产物约定](artifacts.md)。先检查已有成果决定复用或续跑，再为待执行的 LLM 阶段解析 [task-defaults.json](../task-defaults.json)。

按用户顺序逐篇处理，每篇先正文、后补充 PDF；每个文档依次完成下表四阶段。各阶段首次使用前完整读取对应技能；同一阶段后续文档复用已读规则。审稿目录取代组件默认的 `library/` 路径，不调用入库或笔记流程。

| 阶段 | 组件技能（项目根目录下） | 输入与验收 |
| --- | --- | --- |
| 提取及全文格式校对 | `.agents/skills/paper-extract/SKILL.md` | 源 PDF 的绝对 `--input`、记录目录的绝对 `--out-dir`；包含独立 LLM postprocess。检查 manifest 为 `ok`、校对状态为 `done` 或 `skipped_no_change`、报告存在、页数与 PDF 一致及引用图片存在。 |
| 公式修复 | `.agents/skills/formula-fix/SKILL.md` | 就地修复 `fulltext.md`；按组件检查报告、公式定界符、残留和歧义。 |
| OCR/Markdown 修复 | `.agents/skills/markdown-fix/SKILL.md` | 独立阅读全文并修复 `fulltext.md`，保留已修公式；按组件检查报告、标题、噪声及内容范围。即使格式校对已处理相似问题，也保留本阶段独立审阅。 |
| 中文全文翻译 | `.agents/skills/paper-translate/SKILL.md` | 从修复后的全文生成同目录 `fulltext.zh-CN.md`，包括图注和表格文字；核对章节覆盖、公式、引用及图片链接，记录验证结果。 |

主 Agent 按执行配置为四个 LLM 阶段分别派发子 Agent，前三阶段使用组件要求的原始任务 prompt；翻译子 Agent 执行 paper-translate 的完整流程。传入审稿规则、组件技能、绝对路径和必要上下文，子 Agent 不再次委派同一阶段，不并行修改同一文件。

每阶段验收后更新完成记录，提取及翻译后按产物约定规范化元数据路径。可确认的提取遗漏（如有图注却缺源图）需对照 PDF 修复并记录；歧义按组件规则保留。验证失败时停止该文档后续阶段，保留成果并报告。沿用组件的启动重试与覆盖规则；不自动使用会清理旧产物的 `--overwrite`。

## 交付

以 `paper.json` 提供正文和补充材料入口，`assets/review-prepare.json` 提供准备进度，阶段报告保留阅读所需警告；字段、路径基准和历史兼容规则见本技能的产物约定。加载模式读取这些文件，无需新增索引或改写 `review.md`。

完成时给出实际存在的原文、中文全文、补充材料及报告链接，列出复用阶段、歧义、缺失和非 PDF 材料。仅所有目标 PDF 的四阶段均验收通过时报告准备完成，并提供 `$review-workspace 加载 <稿件目录名>` 作为后续入口。已有完成摘要可复用；默认不再生成重复摘要或加载报告。
