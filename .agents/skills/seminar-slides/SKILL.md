# 学术组会幻灯片

处理演示文稿时，使用当前可用的 Presentations 技能及其制作和检查流程。

## 任务与文件

- 根据请求确定制作、修改或审阅范围。审阅只提供建议；局部修改不重做全稿。
- 从已有材料确定主题、受众、时长、语言和交付要求，仅询问影响任务推进的缺失信息。
- 修改时重新读取用户最新人工修改稿，不依赖旧版本或缓存。无法确定编辑原稿时先询问。
- 输出到用户约定目录；未指定时使用当前项目的 `.agent-tmp/<task-id>/output/`。修改已有稿件时直接覆写用户最新原文件，不另存版本；用户明确要求另存时遵循要求。空模板文件不覆写。
- 文件名、文档和辅助代码使用简洁、准确的词语，只保留本次任务需要的内容。

## 模板与格式

- 格式以用户提供的空模板为准，用户明确要求和已确认的例外优先。开始制作前确定可访问的空模板路径；未提供模板时请求用户补充。
- 使用空模板的文本框、占位符、母版和版式。新增页采用匹配版式，也可复用符合空模板或已确认例外的页面。缺少空模板时请求补充，不自行替代。
- 保留编辑原稿的内容和人工修改，只调整本次要求的属性。恢复格式时对照空模板的对应对象和段落层级；不确定的差异先询问，不顺带重置整稿。
- 分别处理文本框位置、文本垂直对齐和段落水平对齐；行距、段前、段后分别设置。替换文字或字体时保留其他段落属性及模板继承关系。
- 字体遵循空模板；空模板未定义的英文字体默认 Arial，中文沿用模板。原生公式使用数学字体，不强行改成正文字体。

## 内容与语言

- 默认主要使用英文，Introduction 使用英文，必要时用少量中文解释概念或符号；用户另有语言要求时遵循要求。
- 所有幻灯片的讲者备注统一使用中文，默认写成口语讲稿。备注应使用自然、直接、适合现场讲述的中文，解释这一页在做什么、图或公式怎么看、为什么值得关注。必要时用简单例子解释符号和推导。制作过程、版本记录、字体参数和图片分辨率等信息放在工作记录中，来源放在备注末尾。
- 使用朴实、准确的学术表达，术语与原文一致。技术词汇只用于表达相应概念，不用复杂措辞替代直接表达。
- 根据受众和时长安排内容，每页突出一个主要信息。单篇论文说明已有研究、未解决问题、本文方法、证据和局限；多论文专题按共同问题比较；研究进展说明目标、结果、问题与下一步。不固定页数或章节。
- 方法讲解根据需要说明输入、输出、关键操作与公式，解释首次出现的重要符号。使用可编辑原生公式；已有人工插入的图片未经要求不替换。
- 长篇解释和推导放入备注，关键结论与实验条件留在页面上。区分已有方法、作者贡献和自己的解释。
- 先使用用户材料及项目论文库中的原文，把事实核查纳入首次交付。写作时对照原文，口语化改写后再次核对关键事实，尤其是贡献归属、公式条件、比较对象、实验预算和指标含义。涉及已有方法的能力时查阅被引用原文。正文、公式、图示或图注不一致时说明依据；将作者结论、自己的推导和主观判断明确区分。在图注、脚注或备注中标明论文、图表号或页码。

## 图表与交付

- 学术表格默认使用可编辑三线表：顶线、表头下横线、底线，无竖线；用户指定其他样式时遵循要求。
- 论文图优先采用原始矢量或从 PDF 渲染。栅格图按最终显示尺寸至少 300 PPI；素材不足时说明，不以插值放大代替高清素材。
- 检查图片裁剪和比例，保留必要的图内文字与图例，排除相邻正文。内容过密时按讲解需要拆页或放大局部。
- 图表盘点列出来源图号、内容、所在幻灯片和缺失情况；按用户确认的范围添加，使用实际显示页码。
- 交付前渲染并检查新页和修改页，确认文字、图片、公式和表格清楚完整，无关内容与格式未变。全局修改时检查全稿；说明未完成的检查。
